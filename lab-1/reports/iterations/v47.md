## Сравнение с лучшим

Лучший TabM по среднему 3 seeds — 256 × 3, dropout 0.1: 0.3632 ± 0.0522. Сейчас: 0.3346 ± 0.0155 (Δ −0.029), test 0.3292 (Δ −0.006). Лучший ран лабы по val остаётся v13 (TabLDM, 0.3933).

Гипотеза H4: не ясно, разница в пределах шума. «Не хуже v14» выполнено: 0.3346 против 0.2886. «Меньше переобучения» не подтвердилось: разрыв loss −0.065 при std 0.15–0.18, val loss на последней эпохе выше (1.103 против 0.996), минимум val loss хуже на 0.018.

## Интерпретация

- Средняя разница −0.029 создаётся одним seed 42: там −0.107, на seeds 43 и 44 dropout 0.3 даёт +0.011 и +0.010. Значение 0.4235 у v26 похоже на выброс, а не на свойство dropout 0.1.
- Dropout 0.3 уменьшил разброс по seeds в 3.4 раза (std 0.0155 против 0.0522) и по val balanced accuracy (0.0179 против 0.0641). Это самый заметный эффект H4: модель стабильнее, но не точнее.
- Переобучение после лучшей эпохи dropout не убрал: val loss растёт у всех трёх ранов. В TabM k = 32 подсетей с общими весами уже регуляризуют модель, а early stopping по val отсекает рост loss, поэтому добавочный dropout мало меняет лучшую эпоху.
- lr / wd подобраны под 512 × 2, dropout 0.1. Более сильная регуляризация может сдвинуть оптимум lr, так что вывод — для фиксированного lr.

## Что дальше

- Финальный TabM: 256 × 3, dropout 0.1 или 0.3 — по F1 они не различимы; `/tune` lr / wd для 256 × 3 (30 trials, ~3 мин), затем 5 seeds и сравнение с k = 64 (v20).
- TabLDM: H5 (n_estimators 1 / 4 / 8 / 16 / 32, качество и время inference), H6 (`enhance_candidates`), H7 (поправка вероятностей редких классов по val). Для «≥ 3 гипотезы на модель» у TabM уже есть H1–H4.
